Library Version
=================

This section documents the compile-time version macros shared by the RTP,
OTA and FWUAL libraries. To retrieve the version at runtime, use
:cpp:func:`el2go_rtp_get_version` (see :doc:`main_api`), which returns the
values of these macros.
